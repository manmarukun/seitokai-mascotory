# seitokai-mascotory

生徒会マスコットを、画像生成AIで「同じキャラのまま」作り続けるためのプロンプト変換ツールです。
キャラの固定設定（体の形・色・小物）はそのままに、ポーズだけを選んで英語プロンプトを作ります。

## 使い方

1. キャラ（A・B・C）を選ぶ
2. 必要なら体の形と色を変える
3. ポーズ・目の表情・向き・構図・背景を選ぶ
4. 「プロンプトをコピー」を押し、画像生成AIに貼り付ける

最初に気に入った1枚を参照画像として添付し、「参照画像を添付する」にチェックを入れると、同じキャラになりやすくなります。

## 構成

- `index.html` … ツール本体（1ファイルで完結。外部ライブラリなし）

キャラの設定は `index.html` 内の次の配列を編集します。

- `CH` … キャラ（名前・体の色・小物の色・体の形）
- `SHAPES` … 体の形（英語の説明文）
- `POSES` / `EYES` / `VIEWS` / `COMPS` … ポーズ・目・向き・構図

## GitHub Pagesで公開する

1. リポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」にし、ブランチ（main）とフォルダ（/ (root)）を選んで保存する
3. 数分後に `https://<ユーザー名>.github.io/seitokai-mascotory/` で開ける

## 注意

- 生成AIの利用規約を確認し、生成物を学校の公式用途に使ってよいかを確かめてから使ってください。
- 既存のキャラクターに似ていないか、公開前に画像検索などで確認してください。
